## ZK 分析收获

在 Moven 分享会后写了 ZK 对 AuditAgent 的启发分析：

**三个方向评估**：
1. ZK 证明审计过程正确 → 当前不需要，EAS 够用
2. ZK 隐藏漏洞细节 → 好想法但成本高
3. ZK 验证 Agent 执行 → 工程量太大

**核心结论**：
> 审计结果的可信性不依赖于审计过程的公开，而依赖于验证机制本身。

EAS + NFT 是 ZK 的简化版，当前阶段足够支撑「可验证审计」叙事。
