## 学习笔记

### 支付场景 Workshop 要点
- Agent 支付的核心挑战：授权边界（预设额度内自主执行，超出需人工确认）
- HTTP 402 + x402 协议：Agent 自主支付的基础设施，实现微支付
- 风控边界设计：单笔上限、日累计上限、白名单合约、异常检测
- 与 AuditAgent 关联：调用付费 API 时可通过 x402 自动付费

### 黑客松赛道实战要点
- MVP > 功能全面：先跑通核心流程，再扩展
- README 是门面：评委第一眼看 README
- Demo 必须稳定：跑不通的 Demo 比没有更糟
- 30 秒电梯演讲：问题 + 方案 + 效果

### Cobo 赛道分析
- CAW (Cobo Agentic Wallet) 核心能力：托管/结算/分润
- 三个结合方案：
  1. 审计即服务 + 自动结算
  2. Agent 间协作 + 分润
  3. 审计结果 + 链上保险
- 结论：AuditAgent 与 Z.AI 更匹配，但 Cobo 也可做商业化方向
