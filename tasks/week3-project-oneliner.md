## 项目名称
AuditAgent — AI 多代理智能合约安全审计系统

## 三句话说明

**解决什么问题：** 2024-2025年因智能合约漏洞损失 $3.8B+，传统审计工具只能检测已知模式，无法理解代码语义和生成修复方案。AuditAgent 用 5 个 AI Agent 协作，不仅检测漏洞，还能自动生成修复代码并用 PoC 验证修复有效性。

**给谁用：** DeFi 协议开发者、智能合约审计师、安全研究人员。在部署前快速获得 AI 辅助的安全审计报告。

**Week 4 最小 Demo：** 输入一个含已知漏洞的 Solidity 合约 → Agent 自动检测漏洞 → 生成修复补丁 → 用 Forge 跑 PoC 验证修复 → 输出审计报告（含漏洞位置、严重级别、修复代码、验证结果）。

## 技术路径

```
输入合约 → Slither 静态分析 → AI Agent 语义审计 → 漏洞分类
    → 修复策略制定 → 代码生成 → Forge PoC 验证 → 审计报告 + 链上证明
```

## 与 Z.AI 赛道的关系

整个审计流程是一个 Long-Horizon Task：需要多轮 Agent 协作、持续调用工具（Slither/Forge/RPC/RAG）、迭代修复直到验证通过。
